# Layerstead Technologies — Website V2

A clean, responsive Next.js + Tailwind starter for Layerstead Technologies.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before launch

1. The consultation form is already connected to Formspree form ID `xrpglbqn`. Submit one test request locally and confirm it arrives at the email connected to that Formspree account.
2. Replace the temporary `LS` header mark with the finalized Layerstead logo asset.
3. Run `npm run build` before deployment.
4. After deployment, submit one more live-form test from the production URL.
